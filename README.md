# Unifor Biblioteca — app

Expo (React Native + TypeScript) app of the Unifor Biblioteca project. The current
code is a **throwaway passkey prototype**: one screen with buttons and a log, used to
test the passkey flow against the local API (`unifor-biblioteca-api`). It is not the
final app.

- Android package: `app.unibooks.biblioteca`
- Passkeys do not run in Expo Go: use a development build (`expo run:android`).

## Requirements

- Node 24, JDK 17+ and the Android SDK (`ANDROID_HOME` set), with an emulator or device.
- The API repository running locally with the Firebase emulators (see its README).
- An Android emulator with a Google account signed in and a screen lock (PIN), so
  Credential Manager can create passkeys.

## Run

1. Start the Firebase emulators and the API (in the API repository):
   `npm run emulators`, `npm run seed` and `npm run dev` (port 8080).
   In its `.env` set `PASSKEY_RP_ID=uni-books.app` and
   `PASSKEY_ANDROID_ORIGINS=android:apk-key-hash:<SHA-256 of the debug certificate, base64url>`.
2. Publish `/.well-known/assetlinks.json` on `https://uni-books.app` (see
   `assetlinks.json`). Android checks it before allowing a passkey for the RP ID.
3. In this repository:

   ```sh
   npm install
   npm run android   # prebuild + Gradle build + install on the open emulator
   ```

   Later runs can use `npm start` (Metro with the dev client) once the app is installed.

On the Android emulator the computer is `10.0.2.2`, so the app talks to the API at
`http://10.0.2.2:8080` and to the Auth emulator at `http://10.0.2.2:9099`
(see `src/config.ts`).

## Test flow

1. **Sign in with password**: matricula + password of a seeded student.
2. **Create passkey**: asks the API for options, creates the passkey on the phone and registers it.
3. **Sign out**, then **Sign in with passkey** (needs the matricula): options, phone
   authentication, `verify`, `signInWithCustomToken`.
4. **Show /me**: `GET /me` with the Firebase ID token.

Every step and error appears in the log.

## Debug certificate

The development build is signed with `android/app/debug.keystore` (generated by
`expo prebuild`; the folder is not versioned). Its SHA-256 fingerprint:

```sh
keytool -list -v -keystore android/app/debug.keystore -alias androiddebugkey -storepass android
```

Convert the fingerprint to base64url (no `=`) for `PASSKEY_ANDROID_ORIGINS`:

```sh
node -e "console.log(Buffer.from(process.argv[1].replace(/:/g,''),'hex').toString('base64url'))" <SHA-256>
```
