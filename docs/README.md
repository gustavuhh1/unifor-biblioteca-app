# Documentos do projeto

Cópia dos documentos oficiais do Unifor Biblioteca, exportada em 20/10/2026 para orientar o desenvolvimento do app. Os originais ficam no Projeto do Claude; quando um deles mudar, esta pasta é atualizada no mesmo PR da mudança.

| Arquivo | Conteúdo |
|---|---|
| `escopo.md` | Documento de escopo: o que entra, o que fica fora, regras, autenticação, decisões e riscos |
| `requisitos.md` | 85 requisitos funcionais e 28 não funcionais |
| `regras-e-decisoes.md` | Regras de negócio e decisões de design e de telas |
| `modelo-de-dados-firestore.md` | Formato dos dados (o app recebe tudo pela API) |
| `design-system/` | Tokens, regras de uso e API dos componentes do design system |
| `api-openapi.json` | Contrato das rotas da API prontas em 23/10 (acesso: cadastro, senha, passkey, /me, logout; acervo: busca, página do livro e gestão) |
| `infra.md` | Infraestrutura, pacote Android, passkey e nomes das variáveis (sem valores secretos) |

Em caso de dúvida ou contradição entre eles, a decisão é do Gustavo.
